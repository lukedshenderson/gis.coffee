    Branch

    A branch is your own line of work, separate from the shared main branch.

    Create a branch

    Start from the shared project, then give your change its own safe place to grow.

    Step 1 of 7

    Make a branch

    Branches let you work without changing the team's shared main branch.

    Stage the files

    Staging chooses which edits go into the next commit. Pick at least one changed file.

    Commit the change

    A commit is a named snapshot that explains one change.

    Push your branch

    A push sends your local branch to the remote repository so GitHub can see it.

    Ready to push

    Your commit is local until you push it.

    Open a pull request

    A pull request asks to merge your branch into another branch; it starts a review, not an automatic merge.

    Review before merging

    A teammate checks the change, asks questions, or approves it before it joins the target branch.

    Pull request #1 · Review requested

    Merge the pull request

    Merging brings the reviewed work into the target branch.

    Approved and ready

    Your branch can now be merged into main.

    Quick glossary: clone, fork, and origin
    Clone
    Download a repository to your computer so you can work on it locally.
    Fork
    Create your own GitHub-hosted copy of someone else’s repository.
    Origin
    The usual nickname for the remote repository your local project connects to.
